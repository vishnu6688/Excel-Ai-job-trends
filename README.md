# Ai-jobs-market in 2025-2026
Dataset and analysis of Ai trends
 

## Dataset Scope & Context; 

The dataset covers global job posting records collected from January 2025 through March 2026. All financial figures are standardized in USD ($).

1. ### Tab Structure:

  The workbook is organized into three primary operational layers: an executive KPI summary (`Dashboard`), aggregated multi-dimensional summaries (`Analysis`), and a 1,500-record transactional dataset (`Data`).
